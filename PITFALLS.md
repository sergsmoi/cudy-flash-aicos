# 🪤 Все грабли (и как их избежать)

## Stock Cudy
| Проблема | Решение |
|----------|---------|
| 2.5.30 login требует RSA-OAEP | nonce + salt + публичный ключ, шифрование OAEP SHA-1 |
| Upload требует trusted change event | setFileInputFiles + dispatch change, или через upload.js |
| Proceed + Apply — два шага | Сначала upload, потом Proceed, потом GET reboot/apply |

## Ростелеком блокировки
| Проблема | Решение |
|----------|---------|
| Блокирует IP целиком по TCP | Порт 443 (HTTPS) часто пропускают |
| 8443 блокируется | Никогда не используй! |
| Блокирует пулы дата-центров | RackNerd 443 работает, HIP Германия — нет. |

## Xray на OpenWrt
| Проблема | Решение |
|----------|---------|
| TUN отрезает SSH | Только TPROXY! |
| Не слушает IPv4 | Добавить "listen":"0.0.0.0" |
| Несовместимость версий Reality | Xray 25 vs 26 — держи одинаковые |
| procd crash loop | Проверь JSON (sed ломает) |
| "device or resource busy" | Удали старый TUN: ip link delete xray0 |
